# Write for the person using the page

Lead with a place, a question or the next useful action. Use plain British English, concrete detail, warmth and occasional original wit. Do not imitate an individual's catchphrases. Do not make safety, access, privacy or errors the punchline.

Put methods and record counts in labelled expandable detail. Keep sources accessible. Never rename records as species, animals, sightings today or independent observations. Missing information is not wildlife absence. Do not disguise an outage as success or promise coming soon.

Use local guide instead of ecology hub in everyday copy, wildlife records instead of occurrence metadata, and looking up instead of querying. Preserve internal identifiers and scientific names.

Scope: shared county wildlife cards, county discovery, Cambridgeshire search and status text, home/venue landing, venue studio headings, published guides, enquiries, professional landing and shared footers. This is not a completed audit of every private workspace, admin screen, legal document, source quotation or backend error.

Integration: stacked on PR50. Apply the copy changes to the current Abacus integration; do not replace newer ZIP55 county maps or Kilkenny/Down editorial content with the older base page. Preserve PR48. No filters, API contracts, permissions or database migrations change. This does not resolve zero eligible records or populate missing places.

Verify populated/empty wildlife results, unsupported county, unavailable source and retry. Supporting details retain counts, limits, notes and original check time. Full host build and browser verification remain release gates. No deployment performed.
